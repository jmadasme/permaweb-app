# rec/ — video explicativo

Este directorio contiene el video asciinema de **PermaDrop: archivos permanentes con saldo prepago** y el reproductor
que se usa en la página del proyecto.

- `permaweb-app.cast`: grabación original (asciicast v2).
- `permaweb-app.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:13. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
